# Grilling Format

The round format for sessions with `/wayfinder`, `/grill-with-docs` and `/grilling`. `drive` reads this file as `grill.format` in `docs/drive/project.yml`.

## Each round

1. An optional reply to the previous decision, or an introduction.
2. One question that starts with a W word (what, which, why, where, who) or with How.
3. Numbered options, at least 2-3.
4. A Recommendation at the end, with the reason.

## Wording

- Use simple words and an inverted pyramid: the answer first, the detail after.
- Use technically precise words. Do not invent words.
- The user asks a follow-up when technical depth is needed.
