# Agent Docs

How agents work in this repo. `AGENTS.md` (also `CLAUDE.md`) links each file.

- `triage-labels.md`: the five triage labels.
- `domain.md`: glossaries and Decision records.
- `reference-repos.md`: the index of reference repos.
- `grilling-format.md`: the round format for grill and wayfinder sessions.
