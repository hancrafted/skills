# Drive review

The calibration answers for every decision page of this project. Fill each section once; /drive passes this file to the
page skill as the caller's inputs, so the page skill asks nothing.

## Mode

Standalone HTML decision page.

## Audience

The Operator, reading cold, in plain words.

## Layout

Quick wins first, then architectural options. One card per option with every field; the recommendation is marked with its reason.

## Depth

The option field table. No code blocks.

## Fidelity

Text and diagrams only. Show before/after as ordered steps or a small diagram.

## Feedback route

The Operator answers in chat with option labels.

## Review width

1280px wide, narrow 390px.
