# Glossary map

Each skill is a context. Its glossary ships inside the skill, because the agent reads it at runtime. Its Decision records stay in this repo, under `docs/decision-records/<skill>/`, because the installer ships every file in a skill folder. Records that span the whole repo sit directly in `docs/decision-records/`.

## Contexts

- **Drive**: how an Orchestrator runs a Workflow with the Operator and Subagents. Glossary: [skills/drive/GLOSSARY.md](./skills/drive/GLOSSARY.md). Records: [docs/decision-records/drive/](./docs/decision-records/drive/).

A skill with no glossary and no records has no row. Add one when its first term or decision settles.
