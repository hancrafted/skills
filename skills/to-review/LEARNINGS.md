# Learnings

Read this file before improving the skill. Feedback about the page's form belongs here; feedback about which Option is right belongs to the caller.

## Review lenses

- **Picking:** the pick target is visible without reading the Option cards. Target size alone does not prove that a person can find it.
- **Reader load:** the simple view is scannable. Word counts and depth controls inform review; they do not prove that the decision reads clearly.
- **Altitude:** code decisions judged by their effect lead with principles, benefit, impact, cost and trade-offs. The detailed layer teaches the principle and supplies the precise evidence.

## Recording feedback

Keep each open lesson under Lessons with a short title, the person's quote, the session id and date, the page path, measured evidence, and the rule or check that needs attention. Use domain-neutral wording for a reusable concern; keep concrete evidence labelled as evidence.

Commit a lesson with `/commit`. Cite it by title. Resolved lessons belong in the skill's applicable rule or reference.
